# Rerouted Results Website

Static one-page website for GitHub Pages.

## Upload to GitHub

Upload these files to your repository:

- index.html
- style.css
- assets/logo.png
- assets/privacy-notice.pdf

The assets folder must be uploaded with the two files inside it.

## Contact form

The contact form uses FormSubmit and sends to:

info@reroutedresults.com

The first form submission may send a confirmation email to that inbox. Confirm it once.

## GitHub Pages

1. Go to Settings > Pages.
2. Source: Deploy from a branch.
3. Branch: main.
4. Folder: /root.
5. Save.
